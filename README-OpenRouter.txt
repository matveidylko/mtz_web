ПОДКЛЮЧЕНИЕ ИИ-ЧАТА К САЙТУ МТЗ 82.1
======================================

Вариант 1. Быстрая личная проверка
----------------------------------
1. Создайте API-ключ на https://openrouter.ai/keys
2. Откройте сайт и перейдите в раздел «Вопросы о проекте».
3. Раскройте «Подключение ИИ-модели OpenRouter».
4. Вставьте свой ключ в поле личного API-ключа.
5. Оставьте модель openrouter/free и нажмите «Сохранить настройки».

Ключ хранится только в памяти открытой вкладки и не записывается в HTML,
localStorage или cookies. После перезагрузки страницы его нужно ввести снова.
Этот режим предназначен для личной проверки. Не вставляйте общий ключ
проекта в опубликованный index.html: посетители смогут извлечь его.

Вариант 2. Публичный сайт через Cloudflare Worker (рекомендуется)
------------------------------------------------------------------
1. Создайте бесплатный Worker в Cloudflare Dashboard.
2. Загрузите в него файл openrouter-worker.js.
3. В настройках Worker добавьте переменную ALLOWED_ORIGIN со значением
   точного адреса сайта, например https://mtz-vr.pages.dev
   (без завершающего слеша).
4. В разделе Secrets добавьте OPENROUTER_API_KEY и вставьте туда ключ
   OpenRouter. Это секрет сервера, не сайта.
5. Сохраните и разверните Worker. Скопируйте его URL вида
   https://mtz-vr-ai.<ваш-аккаунт>.workers.dev
6. На сайте откройте «Подключение ИИ-модели OpenRouter», вставьте URL Worker
   в поле «URL защищённого прокси» и нажмите «Сохранить настройки».

Чтобы Worker подключался автоматически для всех посетителей, откройте
index.html и найдите строку:
  const AI_CONFIG={proxyUrl:'',apiKey:'',model:'openrouter/free'};
Укажите URL Worker в proxyUrl, например:
  const AI_CONFIG={proxyUrl:'https://mtz-vr-ai.example.workers.dev',apiKey:'',model:'openrouter/free'};
После этого не нужно просить посетителей вводить API-ключ.

Worker принудительно использует маршрутизатор openrouter/free, чтобы клиент
не мог переключить запрос на платную модель. Для публичного запуска всё равно
настройте Cloudflare Rate Limiting / защиту от автоматических запросов:
ограничение Origin и CORS не являются полноценной защитой от прямых HTTP-вызовов.

О бесплатном режиме
-------------------
OpenRouter автоматически выбирает доступную бесплатную chat-модель через
openrouter/free. Доступность конкретных моделей может меняться. У бесплатных
вариантов есть лимиты и временная недоступность отдельных провайдеров.

ИМПОРТ FBX И ФОНА
=================
- Откройте в 3D-вьюере «Импорт собственных FBX-моделей и настройка фона».
- Выберите слот: трактор, плуг, отвал, прицеп или косилка.
- Нажмите «Выбрать FBX». В системном диалоге можно выбрать сам .fbx и
  связанные с ним изображения текстур (PNG/JPG/WEBP) одновременно.
- Модель центрируется и масштабируется автоматически. Если она ориентирована
  не той стороной, измените «Поворот Y», затем подстройте масштаб и высоту.
- «Сбросить FBX» возвращает процедурную модель выбранного слота.
- Для фоновой картинки загрузите PNG/JPG/WEBP. Файл обрабатывается локально.

Можно также положить модели рядом с index.html в папку models:
  models/tractor.fbx
  models/plow.fbx
  models/blade.fbx
  models/trailer.fbx
  models/mower.fbx

Если FBX не найден, сайт проверяет соответствующий .glb. Если нет ни FBX,
ни GLB, продолжает использовать процедурную модель. Для FBX с внешними
текстурами храните картинки в той же папке assets и загружайте их вместе
с FBX через файловый диалог, либо используйте встроенные/запечённые текстуры.

ТЕХНИЧЕСКИЕ УСЛОВИЯ
===================
- Запускайте сайт через локальный HTTP-сервер (например, VS Code Live Server),
  а не двойным щелчком по index.html: ES-модули Three.js требуют HTTP(S).
- FBXLoader из Three.js r160 поддерживает FBX версии 7.0+ (ASCII) и 6400+
  (Binary). Некоторые старые FBX-файлы могут не загрузиться — экспортируйте
  из Blender в FBX 7.4 Binary или ASCII и проверьте текстуры.
- Внешние модели импортируются в текущую сцену Three.js; для сложных
  иерархий, скелетной анимации или нестандартных материалов может потребоваться
  предварительная подготовка/экспорт в Blender.
